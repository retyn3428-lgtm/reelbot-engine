# ReelBot — результаты

## Рабочий экран проекта и навигация
- Пользователь видит облачный статус, разделы «Проекты», «Референсы», «Пресеты» и «Очередь».
- Главный экран объясняет сценарий «референс → исходники → стиль → очередь».
- Макет работает на широком экране и на узком мобильном экране.

## Загрузка материалов
- Есть отдельные режимы загрузки референса и исходников.
- Пользователь может выбрать файлы через системный диалог и видит список добавленных файлов.
- Интерфейс отделяет видео-референс от исходных дублей и не смешивает их.

## Лаборатория стиля
- Можно выбрать пресет субтитров.
- Можно выбрать тип плашки и прозрачность стекла.
- Можно выбрать расположение текста.
- Можно выбрать тип зума.
- Справа виден живой вертикальный preview выбранного сочетания.

## Пресеты и очередь
- На экране видны сохранённые монтажные пресеты с описанием состава.
- Пользователь может добавить проект в очередь обработки.
- Очередь показывает состояния «ожидает», «анализ» и «готово» как основу для будущего реального рендера.

## Технические ограничения первой итерации
- Реальный MVP-рендер подключён: бот скачивает видео из Telegram, удаляет длинные паузы, расшифровывает речь через Whisper, вшивает субтитры, делает вертикальный 1080×1920 MP4, нормализует голос и отправляет результат обратно в чат.
- Dropbox/OneDrive, выбор стиля, базовый анализ референса и отдельные обработки теперь реализованы в Telegram-коде. Прямые видеофайлы в Telegram ограничены 20 МБ; внешние ссылки должны быть доступны для скачивания.


## Telegram-бот — локальный этап 2026-10-30 (не опубликован)

### Реализовано в рабочем клоне
- `/motion`, `/speed`, `/filter`: обычные/усиленные наезды или без движения; скорости ×1–×1.5 с сохранением высоты голоса; восемь цветовых пресетов плюс исходный вид.
- `/findinsert <тема>`: поиск кандидатов GIF/видео в Wikimedia Commons, фильтр по меткам CC0/Public Domain/CC BY и размеру, выбор результата, запись источника/автора/лицензии и выдача копируемого авторства после сборки.
- `/edit <ID>` открывает готовый проект до срока хранения; `/caption-edit <секунда> <текст>` меняет ближайшую фразу; вставки и плашки можно точечно убрать перед повторной сборкой.
- `/script <тема>` и разбор хука уточнены по уроку: задача ролика, разные типы начала, связность, демонстрация, доказательство и призыв. Без `ANTHROPIC_API_KEY` остаётся каркас; автоматического поиска в Instagram нет.
- Локальные проверки: 7 Worker-тестов и 15 Python-тестов; все 9 фильтров и ускорение ×1.2 проверены через FFmpeg на синтетическом ролике. Дополнительно реальные кадры проверены для смещённой плашки, стеклянной плашки и karaoke с точным временем слова; libass подтвердил выбор локальных Inter, Montserrat и Oswald.
- Настройки `/styles`, `/plate-opacity` (20–80%) и `/font` передаются из Worker в runner. Русская кириллица, полупрозрачная округлая плашка, сдвиг и karaoke-подсветка проверены автоматическими тестами.

### Ограничения и следующие задачи
- Исправление готового ролика пока создаёт полный новый рендер из исходников, а не пересобирает только выбранную дорожку. Настоящая постоянная шкала слоёв, предпросмотр и частичный рендер требуют отдельной разработки и решения о хранении файлов/сроке удаления. Дополнительное хранилище не подключено.
- Запрос к Commons API из облачной среды разработки ответил HTTP 403. После одобренного развёртывания нужно проверить поиск из Worker и загрузить один выбранный лицензированный файл до обещания, что библиотека доступна в продакшене.
- Не реализованы поиск Instagram, панорама/орбита/кран, отдельные звуковые эффекты, смысловой автоподбор и предпросмотр дорожек.
- Этот этап не отправлен в GitHub и не развёрнут в Cloudflare. Не делать push/deploy без явного разрешения.
