# ReelBot — результаты

## Рабочий экран проекта и навигация
- Пользователь видит облачный статус, разделы «Проекты», «Референсы», «Пресеты» и «Очередь».
- Главный экран объясняет сценарий «референс → исходники → стиль → очередь».
- Макет работает на широком экране и на узком мобильном экране.

## Загрузка материалов
- Есть отдельные режимы загрузки референса и исходников.
- Пользователь может выбрать файлы через системный диалог и видит список добавленных файлов.
- Интерфейс отделяет видео-референс от исходных дублей и не смешивает их.

## Лаборатория стиля
- Можно выбрать пресет субтитров.
- Можно выбрать тип плашки и прозрачность стекла.
- Можно выбрать расположение текста.
- Можно выбрать тип зума.
- Справа виден живой вертикальный preview выбранного сочетания.

## Пресеты и очередь
- На экране видны сохранённые монтажные пресеты с описанием состава.
- Пользователь может добавить проект в очередь обработки.
- Очередь показывает состояния «ожидает», «анализ» и «готово» как основу для будущего реального рендера.

## Технические ограничения первой итерации
- Видео ещё не рендерится и не отправляется в Telegram: это следующий серверный этап.
- Dropbox, OneDrive и Bot API пока представлены интерфейсными точками подключения, без запроса пользовательских токенов.
