# ReelBot — план первой версии

## Цель
Собрать личную облачную систему монтажа коротких видео с управлением через Telegram и веб-панелью. Первая версия показывает и проверяет основной пользовательский сценарий: загрузить референс, добавить исходники, выбрать стиль и отправить проект в очередь обработки.

## Подход
Первая итерация — интерфейсный MVP с локальным состоянием и готовыми сущностями для подключения серверной обработки. Следующие итерации подключат Telegram Webhook, Dropbox/OneDrive, транскрибацию, FFmpeg/рендерер, хранение файлов и сохранение пресетов в базе.

## Дизайн
- **Движение:** editorial creator studio — тёмная рабочая поверхность, как монтажная, с крупной типографикой и кислотно-лаймовыми служебными акцентами.
- **Принципы:** один главный шаг на экран; референс и исходники разделены; сложные параметры собраны в компактную «лабораторию стиля»; результат виден до запуска.
- **Цвет:** угольный фон для ощущения инструмента, тёплый бумажный текст для читаемости, лайм для активных состояний и коралловый для предупреждений.
- **Композиция:** асимметричная рабочая область: узкая навигация, широкая зона проекта, вертикальный preview справа.
- **Фирменные элементы:** маркировка `R/` как знак ReelBot, тонкие технические подписи, мини-таймлайны и «живой» индикатор облака.
- **Типографика:** системный гротеск для интерфейса, плотные заголовки, моноширинные технические метки.

## Основные модули
- `client/src/pages/Home.tsx` — dashboard, загрузка, настройки стиля, очередь и пресеты.
- `client/src/index.css` — визуальная система и адаптивная раскладка.
- `server/routers.ts` — будущие tRPC-процедуры проектов, файлов, пресетов и задач.
- `drizzle/schema.ts` — будущие таблицы проектов, референсов, пресетов и render jobs.
- `public/manus-routes.json` — маршрут приложения для платформы.
