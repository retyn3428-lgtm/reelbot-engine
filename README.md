# ReelBot

Исходный код приватного Telegram-бота для сборки вертикальных Reels с русскими субтитрами. Веб-приложение проекта сохранено; рабочий Telegram-бот закрыт allowlist владельца.

## Активный процесс обработки

- `cloudflare/reelbot-gateway.js` — исходник Cloudflare Worker v4. Он принимает Telegram webhook, хранит состояние и очередь в KV `STATE`, защищает внутренние `/runner/*` маршруты токеном и проксирует загрузку исходников и отправку готового видео.
- `runner.py` — Python-runner, который GitHub Actions запускает по расписанию примерно каждые 5 минут и вручную через **Actions → ReelBot runner → Run workflow**. Он забирает задания у Worker, скачивает видео во временную папку runner, монтирует ролик и отправляет его в Telegram. Исходные видео и готовые ролики не сохраняются в репозитории или KV.
- `requirements.txt` — зависимости runner: Whisper, OpenCV, NumPy, Pillow и requests.
- `.github/workflows/reelbot-runner.yml` — активный workflow. У него только разрешение `contents: read`; credentials checkout не сохраняются.

`runner/poll.ts` и `server/telegram.ts` — прежняя TypeScript-реализация обработчика. Активный Actions workflow больше её не запускает.

## Возможности

Runner поддерживает русские фразовые субтитры (до 9 слов, не больше двух строк) и пунктуацию Whisper без смыслового перефразирования; удаление длинных пауз; новые оформления `shifted` (смещённая округлая бордовая плашка), `clean` (белый текст с лёгкой тенью), `karaoke_yellow`/`karaoke_pink`/`karaoke_red` (одно произносимое слово подсвечивается цветом по временным меткам Whisper) и `glass_bar` (ровная полупрозрачная округлая плашка). Ранее сохранённые пресеты `glass`, `powder`, `fuchsia`, `olive`, `echo`, `mixed` тоже поддерживаются. Автоматическое расположение пытается увести подписи в свободную от лица зону; можно выбрать верх или низ. В новой/не настроенной сессии Worker выбирает `shifted`; сохранённый ранее стиль остаётся до его смены кнопкой `/styles`.

Настройки Telegram: `/styles` — оформление, `/plate-opacity` — прозрачность плашки (20–80%), `/font` — Inter, Montserrat или Oswald, `/caption-position` — свободное место автоматически или верх/низ. Фраза Karaoke показывает слова по мере речи; при ручном исправлении фразы бот сохраняет её время и аккуратно распределяет подсветку по её словам.

Для проекта доступны GIF/видео-вставки и текстовые плашки как отдельные слои до рендера. `/layers`, `/undo` и `/remove layer N` показывают и меняют эти слои. `/findinsert <тема>` ищет небольшие GIF и видео в Wikimedia Commons без личного API-ключа, показывает только распознанные метки CC0/Public Domain/CC BY, сохраняет автора и лицензию и предлагает выбрать результат; после сборки отдельным сообщением приходит копируемый список авторства и ссылок. Это не каталог всех мемов или гарантированный источник современных кинофрагментов; внешний запрос к Commons из облачной среды разработки вернул HTTP 403, поэтому доступность API из Cloudflare Worker ещё не подтверждена.

Можно выбрать `/motion` (обычные наезды, без движения, усиленные наезды), `/speed` (×1, ×1.1, ×1.2, ×1.3, ×1.5) и `/filter` (девять цветовых пресетов, включая исходный вариант). Ускорение применяется до распознавания, а обработка звука сохраняет высоту голоса. Движение камеры в текущей версии — это масштабирование/наезды; панорамы, орбита и кран пока не реализованы.

`/script <тема>` ставит задание на три оригинальных варианта начала, сценарий и план кадров, если настроен `ANTHROPIC_API_KEY`; без него бот выдаёт только общий каркас. После готового ролика `/edit <ID>` открывает исходный проект, `/caption-edit <секунда> <текст>` заменяет ближайшую фразу, а вставки и плашки можно менять. Затем бот скачивает исходники и пересобирает MP4 целиком: готовой монтажной шкалы, постоянного предпросмотра и рендера только изменённого слоя пока нет. Референс видео по-прежнему даёт приближённый зум.

Dropbox-референсы показывают отдельно: речь-синхронные белые субтитры, урок по смещённой бордовой подложке и безопасные зоны. Новая `shifted`-подложка рисуется округлой формой через ASS-вектор; цвет и расположение — приближение к образцу, а не автоматическое распознавание одежды/лица. Камерные подписи и экранные промпты из учебных видео не считаются обычными субтитрами.

## Секреты и доступ

Не добавляйте в репозиторий значения токенов, Telegram ID, webhook-секреты, Telegram file IDs, видео или готовые ролики.

- Cloudflare Worker secrets: `TELEGRAM_BOT_TOKEN`, `ALLOWED_TELEGRAM_USER_ID`, `TELEGRAM_WEBHOOK_SECRET`; binding: `STATE`.
- GitHub Actions secrets: `TELEGRAM_BOT_TOKEN`; `GATEWAY_URL` — адрес Worker (если секрет не задан, workflow использует текущий публичный URL); `ANTHROPIC_API_KEY` — необязательный ключ языковой модели для полноценного сценария и подробного разбора текста. Это не вход в Instagram: бот не ищет автоматически ролики других авторов. Без ключа он даёт общий каркас сценария и простую предварительную проверку начала, без числового балла.

Значения хранятся только у провайдера. Runner передаёт сообщения через защищённые Worker-маршруты; не добавляйте значения секретов в логи.

## Проверки и разработка

- `python -m py_compile runner.py` — синтаксис runner.
- `node --check cloudflare/reelbot-gateway.js` — синтаксис Worker.
- `python3 -m unittest discover -s tests -v` — тесты выбора позиции, изменения фраз, шрифта, прозрачности, karaoke-времён и лицензий.
- `node --test tests/reelbot-worker.test.mjs` — тесты Telegram-команд, слоёв, сценарных задач и фильтрации лицензий.
- `pnpm install --frozen-lockfile`, `pnpm check`, `pnpm test` — веб-приложение.
- В `assets/fonts/` лежат шрифты с кириллицей и лицензии SIL OFL. FFmpeg получает эту папку через `fontsdir`; статические regular/bold-файлы помогают libass точно выбирать нужный шрифт на разных runner.
- Для обычного локального видеотеста нужны FFmpeg, зависимости из `requirements.txt` и модель faster-whisper.

GitHub Actions может запускаться с задержкой; интервал проверки не обещает мгновенный ответ. Стандартный лимит входного Telegram-видео — 20 МБ, а готовый ролик должен быть меньше 49 МБ.
